# QQ_COMMANDS — 指令手册

所有指令都有两个等价入口：

- 短指令：`/add 明天下午3点背单词`
- 无冲突入口：`/study add 明天下午3点背单词`

短指令可能与其他插件重名（`/help` `/reset` `/report` 尤其常见）。重名时用 `/study ...`，行为完全一致。

> 指令名唯一性说明：本插件不抢全局事件优先级、不注册同名 tool；`/study` 是命名空间入口。

---

## 使用范围（白名单）

配置项：

```json
{"scope": {"allowed_qq": [], "allowed_groups": [], "group_mode": "per_user"}}
```

规则：

| 场景 | `allowed_qq` | `allowed_groups` | 结果 |
|---|---|---|---|
| 私聊 | 空 | — | **只有机器人主人**能用 |
| 私聊 | 填了 QQ 号 | — | 名单内的人能用 |
| 群聊 | 空 | 空 | 只有机器人主人能用 |
| 群聊 | 填了 QQ 号 | 空 | 名单内的人在**任何群**都能用 |
| 群聊 | 空 | 填了群号 | 该群**所有人**都能用 |
| 群聊 | 填了 QQ 号 | 填了群号 | 名单内的人 + 这些群里的所有人 |

越权时**静默忽略**（回一句友好提示），并写 `command_log`（`reply='denied'`），方便主人排查。

`:per_user` / `per_group`：同一群里两个人是否共用一份数据。默认 `per_user`（互相看不到）。

## 指令表

### 绑定与身份

| 指令 | 说明 | 示例回复 |
|---|---|---|
| `/bind <6位码>` | **仅私聊**。把 App 与当前 QQ 绑定 | `✅ 绑定成功！回到 App 点「完成绑定」…` |
| `/whoami` | 当前主体、已绑定设备数、AI 状态 | `👤 主体：user / 10001` |
| `/unbind <设备标签>` | 吊销某个 App 设备（标签在 App「设备管理」） | `✅ 已吊销 1 台设备（标签 手机）` |
| `/addr` | 返回服务地址；`http.enabled=false` 时说明如何开启 | `🌐 服务地址：http://192.168.1.23:6188/study/` |
| `/umo` | 返回当前会话 UMO（填推送目标用） | `🔗 当前会话 UMO：qq:FriendMessage:10001` |
| `/settings` | 查看个人设置 | 见下 |
| `/settings tz Asia/Tokyo` | 改时区（IANA） | `✅ 已更新：tz = Asia/Tokyo` |
| `/settings brief 07:30` | 改早报时间 | |
| `/settings nudge 20:00` | 改计划督促时间 | |
| `/settings offsets 30,0` | 改默认提醒偏移（分钟，逗号分隔） | |
| `/settings duration 45` | 改默认任务时长 | |

### 日程

| 指令 | 说明 | 示例 |
|---|---|---|
| `/today` | 今日日程（含完成率、逾期提醒） | `/today` |
| `/tomorrow` | 明日日程 | `/tomorrow` |
| `/week` | 本周概览 | `/week` |
| `/add <自然语言>` | AI 解析后落库并回显 | `/add 明天下午3点背单词1小时` |
| `/done <编号或关键词>` | 标记完成 | `/done 2` 或 `/done 背单词` |
| `/del <编号或关键词>` | 软删任务 | `/del 2` |

`/add` 的回复示例：

```
✅ 已写入：背单词
🕐 2026-11-18 15:00 ~ 16:00
📌 来源：qq
```

如果 AI 不可用，会追加一行「（AI 不可用，已用规则解析）」——不会假装成功。
如果没听出时间，会反问一句，不落库。

### 计划

| 指令 | 说明 | 行为 |
|---|---|---|
| `/plan new <目标>` | AI 出计划 | **只回摘要 + 预览，不写入日程** |
| `/apply` | 把上一条未写入的计划落库 | 幂等：重复 apply 返回"已写过" |
| `/plan list` | 计划列表 | 显示状态与 id |
| `/plan show <id>` | 计划详情（逐条列出） | 日期越界会在 apply 时被拒 |

`/plan new` 的回复示例：

```
🗂 计划草稿：考研数学 14 天冲刺
目标：考研数学
截止：2026-11-30｜每天 60 分钟｜共 14 项 840 分钟

  1. 2026-11-18 ·  60 分钟 · 极限与连续
  2. 2026-11-19 ·  60 分钟 · 导数与微分
  ...

这只是预览，还没写进日程。确认无误后发 /apply 落库。
```

### 报表与导出

| 指令 | 说明 |
|---|---|
| `/report [week\|month]` | **纯文本**报表：完成数、完成率、专注时长、计划进度条（字符表示） |
| `/export` | 导出全量 JSON（过长会分段，带 `(1/N)` 标注） |

`/report` 示例：

```
📊 本周报表（2026-11-16 ~ 2026-11-22）
已完成 3/5（60%）
专注时长：180 分钟
计划进度：考研数学冲刺 [████░░░░░░] 3/14
```

### 记忆

| 指令 | 说明 |
|---|---|

## 常见问答

**Q：`/add` 说"没听出具体时间"？**
补一个时间词：`/add 明天下午三点背单词`。回复里会显示解析结果，确认后才写库。

**Q：`/done 2` 报"没找到 #2"？**
编号是**今天列表**的顺序。先 `/today` 看编号；或直接用关键词 `/done 背单词`。

**Q：`/bind` 说"只能在私聊里使用"？**
绑定码涉及把 App 令牌发给某个身份，群里发会泄露，所以限制私聊。

**Q：`/export` 只发了一半？**
超过 10 段的会被截断并提示。用 App 的「设置 → 导出全量 JSON」，或 `GET /api/study/export`。

**Q：群里每个人看到的数据一样/不一样？**
由 `scope.group_mode` 决定：`per_user`（默认）互相独立，`per_group` 整群共用。
